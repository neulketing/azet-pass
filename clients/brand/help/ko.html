AZET Pass 도움말

AZET Pass는 비밀번호 관리자이자 인증 앱입니다. Bitwarden의 오픈소스 앱으로 만들었고, 우리 서버 pass.azet.io로 동기화합니다. 보관함은 동기화 전에 내 기기에서 암호화되므로 우리도 내용을 볼 수 없습니다.

시작하기

  1. pass.azet.io에서 이메일로 계정을 만듭니다. 확인 링크를 메일로 보내며, 24시간 동안 유효합니다.
  2. 마스터 비밀번호를 정합니다. 보관함을 여는 열쇠이며, 우리를 포함해 누구도 재설정할 수 없습니다.
  3. 웹 보관함에서 로그인을 추가하거나, 휴대폰·브라우저에 앱을 설치하고(내려받기) 같은 이메일과 마스터 비밀번호로 로그인합니다.
  4. 다른 비밀번호 관리자나 브라우저에 있던 비밀번호는 가져오기로 옮깁니다.

계정과 마스터 비밀번호

이메일이 로그인 이름입니다. 설정 › 내 계정 › 이메일 변경에서 바꿀 수 있습니다. 새 주소로 코드를 보내고, 마스터 비밀번호로 새 이메일에 맞게 보관함 키를 다시 암호화합니다.

가입할 때 마스터 비밀번호 힌트를 적었다면, 로그인 화면의 마스터 비밀번호 힌트 받기로 힌트를 메일로 받을 수 있습니다. 마스터 비밀번호 자체를 잊으면 보관함을 열 수 없으며, 계정을 삭제하고 새로 시작해야 합니다.

설정 › 내 계정에서 모든 세션 로그아웃, 보관함 비우기, 계정 삭제도 할 수 있습니다.

가져오기

웹 보관함의 도구 › 데이터 가져오기에서 형식을 고르고 파일을 올립니다. Bitwarden(JSON·CSV), 1Password, LastPass, Keeper, KeePass/KeePassXC, Chrome·Edge·Firefox·Safari 비밀번호 내보내기 파일 등 목록에 있는 여러 형식을 지원합니다.

내보낸 파일은 암호화되어 있지 않으니 가져온 뒤 지워 주세요.

내보내기

도구 › 보관함 내보내기에서 JSON, CSV, 또는 계정 키나 직접 정한 비밀번호로 잠근 암호화 JSON으로 저장합니다. 첨부 파일은 내보내기에 들어가지 않으니 항목마다 내려받아 주세요.

항목과 검색

항목은 로그인, 카드, 신원 정보, 보안 메모, SSH 키 가운데 하나입니다. 폴더로 묶고, 즐겨찾기로 위에 둘 수 있습니다. 검색창은 이름, 사용자 이름, 웹사이트 주소, 메모를 찾습니다. 삭제한 항목은 휴지통에 30일 동안 남습니다.

인증 코드(TOTP)는 무료 요금제에서도 쓸 수 있습니다. 로그인 항목에 설정 키를 넣으면 앱이 여섯 자리 코드와 남은 시간을 보여 줍니다.

자동 완성

브라우저 확장: 로그인 화면에서 확장을 열고 로그인을 고르거나, 단축키(기본 Ctrl/Cmd + Shift + L)를 누릅니다. 저장한 웹사이트 주소마다 일치 방식(기본 도메인, 호스트, 시작 문자열, 정확히 일치, 정규식, 사용 안 함)을 정할 수 있고 기본값은 기본 도메인입니다. 확장 설정에서 특정 사이트의 자동 완성을 막을 수 있습니다.

브라우저 자체 비밀번호 저장 기능은 꺼 두는 것이 좋습니다(Chrome: 설정 › 자동 완성 › 비밀번호 관리자, Firefox: 설정 › 개인 정보 › 로그인과 비밀번호).

Android: AZET Pass의 설정 › 자동 완성에서 자동 완성 서비스로 지정합니다. 지원하는 앱에서는 키보드 위에 제안이 나타납니다.

패스키

패스키를 제공하는 웹사이트의 패스키를 AZET Pass에 저장할 수 있습니다. 사이트가 패스키를 만들자고 하면 AZET Pass를 고르세요. 패스키는 로그인 항목에 저장되고, 암호화된 채로 다른 기기에 동기화됩니다. pass.azet.io 자체에 패스키로 로그인하는 기능은 없으니 마스터 비밀번호로 로그인하세요.

2단계 로그인

인증 앱(Google Authenticator, Microsoft Authenticator, Aegis, 2FAS 등)으로 계정을 보호합니다. 설정 › 보안 › 2단계 로그인 › 인증 앱 › 관리에서 QR 코드를 찍고, 앱에 나온 코드를 입력하세요.

같은 화면에서 복구 코드를 꼭 저장해 두세요. 인증 앱이 든 휴대폰을 잃어버리면 복구 코드로 2단계 로그인을 끄고 로그인할 수 있습니다. 복구 코드와 기기가 모두 없으면 우리도 대신 끌 수 없습니다.

Send

Send는 텍스트나 파일을 기한이 있는 링크로 공유합니다. 삭제 날짜, 선택 비밀번호, 최대 열람 횟수, 이메일 숨기기를 정할 수 있습니다. 내용은 브라우저에서 암호화되고, 열쇠는 링크의 # 뒤에 있어 우리 서버로 오지 않습니다. 텍스트 Send는 무료, 파일 Send는 Premium이며 파일은 최대 25 MB입니다.

링크를 받았다면 열고, 비밀번호가 있으면 입력한 뒤 내용을 보거나 내려받습니다.

첨부 파일

Premium에서는 항목에 파일을 첨부할 수 있습니다. 파일 하나에 25 MB, 모두 합쳐 1 GB까지입니다. 첨부 파일은 항목과 함께 암호화됩니다. 아주 오래전에 항목 키 없이 만든 첨부 파일에는 수정 버튼이 보이며, 누르면 항목 키로 다시 암호화합니다.

보고서

데이터 유출 보고서(무료): 계정 이메일이 알려진 유출 사고에 포함됐는지 확인합니다. 조회는 우리 서버를 거쳐 무료 유출 데이터베이스 XposedOrNot에 보내며, 보내는 것은 이메일 주소뿐입니다.

노출된 비밀번호는 Have I Been Pwned에 k-익명성 방식으로 확인합니다. 비밀번호 SHA-1 해시의 앞 다섯 글자만 기기 밖으로 나갑니다. 재사용된 비밀번호, 약한 비밀번호, 안전하지 않은 웹사이트, 2단계 로그인 미사용 보고서는 기기 안에서 계산합니다. 비밀번호 점검 보고서는 Premium입니다.

브라우저 확장은 공개된 피싱 도메인 목록으로, 알려진 피싱 사이트를 열기 전에 경고합니다.

암호화와 키

마스터 비밀번호는 PBKDF2-SHA256(기본 600,000회) 또는 Argon2id로 늘려 키를 만들며, 이 키는 기기 밖으로 나가지 않습니다. 설정 › 보안 › 키에서 방식을 바꿀 수 있고, 바꾸면 다른 세션은 로그아웃됩니다.

지문 문구(설정 › 내 계정)는 공개 키에서 만든 단어 묶음입니다. 다른 기기가 로그인 승인을 요청할 때 맞는지 비교하세요.

계정 암호화 키 교체는 모든 항목을 새 키로 다시 암호화합니다. 키가 노출됐다고 생각될 때 하고, 그 뒤 모든 기기에서 다시 로그인하세요.

웹사이트 아이콘

항목 아이콘은 pass.azet.io를 거쳐 받아 오므로 웹사이트는 내 IP 주소를 알 수 없습니다. 설정 › 화면 › 웹사이트 아이콘 표시에서 끌 수 있습니다.

서버

AZET Pass의 지역은 pass.azet.io 하나이며 Cloudflare Workers와 D1 데이터베이스에서 돌아갑니다. 서버에는 이메일, 마스터 비밀번호 해시를 한 번 더 해시한 값, 암호화된 보관함, 그리고 넣은 경우 라이선스 키가 있습니다. 서버 코드는 GitHub에 오픈소스(MIT)로 공개되어 있습니다. 앱에서 직접 운영하는 서버 주소를 넣을 수도 있습니다.

브라우저 요건

웹 보관함은 WebAssembly가 켜진 최신 브라우저(Chrome, Edge, Firefox, Safari 등)가 필요합니다. 보안 설정이 강하거나 아주 오래된 브라우저는 WebAssembly를 끄기도 하니, 켜거나 다른 브라우저를 쓰세요.

제공하지 않는 기능

AZET Pass는 개인용입니다. 다음 Bitwarden 기능은 AZET Pass에 없어서 앱에도 보이지 않습니다: 조직·공유·컬렉션, Families, 긴급 접근, Secrets Manager, 싱글 사인온(SSO), 패스키로 로그인, 이메일·Duo·YubiKey·보안 키 2단계 로그인. 2단계 로그인은 인증 앱을 쓰세요.
